# zglobal-shop-theme

Shopify theme for **shop.zglobalcorp.com** (ZGlobal B2C storefront).

Based on Shopify's **Dawn** theme, customized for a fresh B2C look:
- ZGlobal navy (#0D2B5E) / gold (#C49A3A) palette on a bright retail base
- Poppins headings, rounded cards with soft shadows, cart drawer
- B2C homepage: hero, shop-by-category, new arrivals (quick add), promo, newsletter

Connected to the store via the Shopify GitHub integration. Commits to the
connected branch deploy to the theme; edits made in the Shopify editor commit
back here.
